# Witch Series Guidelines

Guidelines for collaborative development with AI in the Witch Series.

## Overview

This repository provides general development guidelines for Witch Series projects. It aims to establish a consistent approach to collaborative development that leverages both human creativity and AI assistance.

## Guidelines

### Key Principles

1. **Structured Documentation**: All files should include a README summarizing their purpose and key components.
2. **LLM-Friendly Design**: Code should be structured to fit within typical AI context limits, with clear comments and consistent naming conventions.

To address AI limitations in processing large files, the following design principles are recommended:

- **Folder Segmentation**: Divide functionalities into separate folders to keep file sizes manageable.
- **README Utilization**: Place a README in each folder to provide an overview of its contents.

This approach ensures that AI can efficiently understand and process the project. Developers are encouraged to articulate their thoughts clearly in writing and communicate them effectively to AI collaborators. By following these guidelines, Witch Series projects will remain maintainable, scalable, and accessible to both human and AI collaborators.

### Language Policy

All code, documentation, and comments in this project must be written in English. This ensures consistency and accessibility for a global readers.

### Submodule Usage

If this repository is included as a submodule in another project, ensure that readers are directed to this README to understand the guidelines and structure. Include a note in the parent project's README to reference this guideline.

## File Descriptions

- **README.md**: Provides an overview of the project and its guidelines.
- **coding.md**: Details coding standards and best practices.
- **structure.md**: Defines the directory structure and documentation guidelines.
